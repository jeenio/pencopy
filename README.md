## PenCopy - cópia de pendrives em massa ##

A ideia original era ter um programa fácil de utilizar que pudesse ser usado por pessoas com pouca experiência informática. Questões como formatação de pendrives usb, tipos de sistemas de ficheiros ou até nomes de volumes poderiam ser automatizados por uma ferramenta básica.

Anteriormente, tinha escrito um simples batch file que formatava a pen, fazia um scan por erros, copiava os ficheiros e depois comparava os hashes para ter a certeza que a cópia tinha sido bem sucedida. E replicava o processo para as pens que tinha ligadas a um hub.

Como o número de ficheiros começou a aumentar, percebi que seria mais fácil ter um programa com os vários ficheiros pré-escolhidos, e com um ou dois cliques conseguiria começar o processo. Utilizei o Warp, que é um terminal com agentes de IA para me ajudar com o python e tudo o resto.

Estou confiante que, dentro do universo alvo, o programa poderá ser útil, daí tê-lo tornado público.
